# Marlette Precinct Republicans

**"The Team That Shows Up"**

Official campaign website for the Marlette Precinct Republican Committeeman team.

---

## About This Site

A clean, grassroots-focused website built for the Marlette Precinct Republican candidates. The design emphasizes authenticity, community, and experience — exactly matching the tone of the team photo.

### Features
- Full-width hero with team photo
- Mobile-friendly responsive design
- Working contact form with real email delivery
- Clean Tailwind CSS styling
- Easy to maintain and update

---

## Tech Stack

- **Backend**: Node.js + Express
- **Templating**: EJS
- **Styling**: Tailwind CSS v3
- **Email**: Nodemailer (Gmail)
- **Deployment**: Vercel
